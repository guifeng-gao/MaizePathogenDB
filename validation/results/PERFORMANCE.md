# Computational performance

Performance was measured on the fixed 19,276-ASV query set with BLAST+ 2.17.0.
This is an informational benchmark and does not imply detection performance.

| Database | Wall time | Peak RSS | Per-query time |
|---|---:|---:|---:|
| MPDB | 75.447 s | 369.1 MB | 3.914 ms |
| NCBI ITS_eukaryote | 528.216 s | 154.0 MB | 27.403 ms |
