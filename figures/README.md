# Manuscript Figures

This directory contains the source tables and rendered PNG/PDF files for the
final manuscript figures:

- `Figure1_database_content.{png,pdf}`: panels a-f, including the pipeline.
- `Figure2_validation.{png,pdf}`: panel c is cross-database consistency and
  panel d is the NCBI-nt comparison.
- `Figure3_applications.{png,pdf}`: external database benchmarking,
  real-world application, rescued genera, and runtime.
- `Figure_Pipeline.{png,pdf}`: standalone pipeline panel used in Figure 1.
