Search by DNA Sequence

✓ Fingerprint database loaded (198 species, 225 reference taxa)
How it works: Paste DNA sequence (FASTA format). Extracts 25-mer fingerprints and matches against 198 species reference database.
Recommended: 16S rRNA (≥300 bp) or ITS region (≥300 bp). Minimum 50 bp required.

Submit a New Pathogen

How it works: If you have identified a maize pathogen that is not yet in MaizePathogenDB, submit the information below. The submission will be reviewed and, if approved, the database will be updated.

Requirements: Scientific name must be recognized by NCBI Taxonomy (valid TaxID required). Marker gene sequence must be ≥100 bp. At least one literature reference is required for verification.

Look up at NCBI Taxonomy

Minimum 100 bp. Include a header line starting with >.

You will receive an email confirmation after submission. The review process typically takes 1-2 weeks.

Annotate Species List for Maize Pathogens

How it works: Upload a CSV or TSV file containing species names and/or NCBI TaxIDs. The tool matches each row against MaizePathogenDB and returns an annotated file with pathogen status, matched species, taxonomy, and disease information.

Accepted formats: CSV (comma) or TSV (tab). First row must be a header. Include a column named species, taxon, scientific_name, or TaxID. If no recognized header is found, the first column is treated as the species name.
