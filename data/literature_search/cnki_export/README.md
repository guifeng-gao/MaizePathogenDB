## Coverage caveat

The unique exported set (1,199) is smaller than the reported CNKI search hit
count (1,702). The provided exports therefore do not cover all CNKI hits; 503
unique records are absent from these files. This archive is a partial CNKI
export; full export is not required for the Data Descriptor.
